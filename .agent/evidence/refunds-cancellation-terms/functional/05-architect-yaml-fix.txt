=== ARCHITECT YAML FIX 2026-09-06 | contract-f1.yaml unparseable ===

Reported by team lead: contract-f1.yaml failed to parse —
yaml.scanner.ScannerError: mapping values are not allowed here, line 140 col 24.

Root cause: A11's command was an UNQUOTED plain scalar containing the substring
"id: POLICY-10" (from its awk range pattern `/id: POLICY-10/,/id: POLICY-11/`). YAML's
plain-scalar grammar treats ": " (colon immediately followed by a space) as a mapping
key/value separator wherever it appears, so the parser read "id" as a nested mapping key
inside what was meant to be one scalar command string, and broke.

Fix: wrapped A11's entire command in single quotes (it contains no single quotes of its
own, so no escaping was needed):

  Before: command: awk "/id: POLICY-10/,/id: POLICY-11/" contracts/contract-policy-pages.yaml | grep -q "check-refunds-provisional-figures.mjs"
  After:  command: 'awk "/id: POLICY-10/,/id: POLICY-11/" contracts/contract-policy-pages.yaml | grep -q "check-refunds-provisional-figures.mjs"'
