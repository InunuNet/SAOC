## /societies byte-ratio outlier — investigated, NOT a defect
Beta /societies is 46% of local bytes where every other route is ~75-80%. Cause: the 21
society cards render CLIENT-SIDE after hydration, so the server HTML ships the RSC flight
payload plus a Suspense boundary (11 <template>) instead of rendered cards. The dev server
renders them eagerly, hence 21 <a href="/societies/..."> in local HTML and 0 in beta HTML.
curl cannot verify this route — it needs a browser (dispatched separately).

Data-level proof the NEW build is live on /societies, read out of the flight payload:

  \"meetPlaceholder\":true      21/21
  \"venue\":null                21/21
  distinct \"slug\" entries     21
  surviving fabricated \"meets\":\"...\" strings   0
  surviving fabricated \"venue\":\"...\" strings   0
The fabricated meeting times and venues are gone from the deployed production dataset.
