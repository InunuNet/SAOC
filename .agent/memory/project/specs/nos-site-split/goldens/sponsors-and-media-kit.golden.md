## Revision (final lead ruling: admin is host-neutral)
The session cookie is per host, so the NOS media-kit gate redirects to NOS `/admin/login?next=/media-kit` and the sign-in happens on the NOS host. `next` must be validated as a same-origin path starting with a single `/` (reject `//`, schemes, backslashes); add a minimal validated `next` handler if the login page lacks one. No admin redirect between hosts exists.
